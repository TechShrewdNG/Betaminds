# Betaminds Africa — Website Redesign

Design reference bundle for the Betaminds Africa site redesign: six pages
(Homepage, Digital Ecosystem, Media Services, Academy, Summit, Let's Work) built
as a high-fidelity HTML prototype, plus the documentation needed to rebuild them
in a production codebase.

## Contents

```
design_handoff_betaminds_site/
├── README.md                      implementation spec — read this first
├── Betaminds Africa Site.dc.html  the prototype
├── structure.txt                  client brief + all source copy
└── assets/BETAMINDS-AFRICA.png    logo
```

## Start here

Read `design_handoff_betaminds_site/README.md`. It contains the full design
token set, per-screen layout specs, interaction table, state model, and asset
inventory. The HTML file is a **design reference**, not production code — it
runs on a proprietary template runtime and should be recreated in whatever
framework the production site uses.
